# 双人共学服务

仅同步两人昵称、学习目标、共同计时、房间消息与招呼。个人任务、AI 会话和 AI 密钥不经过此服务。

在本目录安装项目依赖并启动：

```powershell
npm ci
npm start -- --host 127.0.0.1 --port 8787 --data-directory ./data
```

软件的共学服务地址填写 `ws://127.0.0.1:8787/study`，两实例可本机验证。项目开发环境使用 Node.js 22.12.0 或以上；无需全局依赖。

跨网络时需由管理员在可访问服务器运行本服务，通过支持 WebSocket 升级的 HTTPS 反向代理转发 `/study`，客户端填写 `wss://你的域名/study`。房间码不提供网络穿透。此项目没有自动部署、修改防火墙或申请证书的功能，公网环境需单独配置并实测。

HTTP `/health` 仅返回健康状态与协议版本。默认拒绝有浏览器 Origin 的连接；原生桌面客户端不发送 Origin。若需自建网页客户端，在代码启动配置中明确提供 `allowedOrigins`。

服务数据为指定目录的 `rooms.json`，原子写入并保留 `.previous` 备份；重连密钥只保存 SHA-256 摘要。备份也包含房间文字，应按个人服务数据保管。客户端重连凭据只在本机加密保存，不显示或发送给对方。服务不打印消息、凭据或连接地址中的认证信息。

客户端在 `userData/study/receipts.json` 保留经认证连接收到但尚未写入本地统计的终态回执；离开房间或重启后仍可本地恢复，奖励去重标记与统计继续同一次保存。该文件不包含房间重连密钥。

房间最多两人。双方准备后房主启动；暂停后双方需重新准备，房主继续。断线立即暂停并保留席位 90 秒，超时或明确离开结束轮次，余下成员接任房主。服务重启将未结束轮次恢复为暂停，停机时间不算专注。服务端终态回执由客户端一次保存奖励标记与统计；提前结束仅记录有效专注时间，不发完成奖励。

正常关闭保存当前有效时间；计时中每 5 秒保存检查点。异常崩溃恢复只计最后成功检查点之前的时间，因此可能少计至多约 5 秒（磁盘写入失败时以最后成功保存为准），不会计入停机时间或凭空发奖。

默认容量为 500 个持久化房间，每房保留最近 200 条消息、1000 个操作去重编号，最多 32 次成员加入。管理员可通过 `createStudyServer` 的 `maxRooms` 显式调整容量；数据不会自动删除。满容量需管理员归档数据后用新的明确数据目录启动服务。

验证：从项目根执行 `node --test server/tests/*.test.cjs`；测试全部使用根 `artifacts/` 隔离数据。
