# 0.2.0 AI 与双人共学扩展方案

日期：2026-10-10。状态：用户已回复“按照这个方案开工”，完整实施范围获准。支持三协议AI、聊天、任务拆解与跨网络双人共学；实际结果后续记录于VALIDATION.md。

## 产品目标

在现有 Windows 小球同桌中增加可配置 AI、聊天、任务拆解与双人共学。沿用真实角色动画、书桌任务、个人专注、奖励、主题、字体和桌宠偏好。使用者自行选择 AI 服务和模型；两个人可以通过同一个共学服务地址和房间码相遇。

## 使用流程与界面

- 顶栏增加「书桌｜聊天｜双人共学」导航。书桌保持现有左右双栏和底部布置；设置从任何页面进入后返回原页面，切页不暂停计时、不丢输入草稿。
- 聊天页左侧为会话和消息、下方输入与发送/停止；右侧继续保留专注与小球。历史会话按需展开，避免三栏拥挤。回复逐字出现，可停止、复制、新建会话、重试和恢复历史。
- 未配置 AI 时显示「连接你的 AI」入口，跳到设置；不预置伪造回复或在线状态。长回复留在正文，小球只显示简短思考/完成反馈，遵守原动作与悬停提示偏好。
- 任务区增加「帮我拆解」入口，支持输入目标、可用时间，也可显式附带选中的任务。生成可编辑、可勾选的步骤与预计分钟数；点击「加入我的任务」后才批量入库，显示真实添加数量。保留现有平铺任务，父任务不自动完成，计时不自动开始。
- 共学页提供昵称、创建房间、输入房间码加入。房间显示两个实际动画小球、双方在线/准备/专注/暂停状态、共同倒计时和文字聊天；点击同伴小球发送轻量打招呼动画。创建后的等待状态不伪造第二位成员。
- 浅/深/系统主题及导入字体共用；验收默认 1040×780 和最小 880×680。长模型名、回复和房间状态可换行；聊天输入与发送/停止保持可达。

## AI 接入

建议第一轮支持三类文本协议：OpenAI 兼容 Chat Completions、Anthropic Messages、Gemini GenerateContent。支持多个连接配置，每个配置包含显示名、协议、服务地址、API Key 和模型 ID；服务商预设只用于帮助填表，可以自定义地址和手填模型。OpenAI 兼容服务包括能实际提供该协议的 DeepSeek、通义、中转或本地服务；不能把协议选择描述成无条件兼容所有厂商和所有模型。

- 设置新增「AI 连接」分组，顺序为服务商/协议、地址、密钥、模型、保存与测试。模型列表成功读取后再显示；服务不提供列表时仍可手填。保存配置与测试连通分别显示结果，不把已保存当作已接通。
- 支持流式输出、停止、超时和错误说明；切换厂商/模型只影响下一次请求。每个会话同一时间最多一个生成，取消后保留已经收到的文字。
- 只在明确发送、拆解或测试连接时联网；不后台发送任务、房间聊天或自动消耗模型额度。附带任务在发送前显示清楚，可移除。AI 输出只作为文本/建议，不执行代码、IPC 或自动改变偏好。
- 第一轮不加入图片、语音、工具调用、网页搜索及 OpenAI Responses；需要这些协议能力时另扩适配器。实际接口规范在实现时核对各厂商官方文档。

## 密钥与聊天保存规则

- API 请求由 Electron 主进程执行，renderer 继续保持 `connect-src 'none'`，使用限定的主面板 IPC。
- 密钥通过 `safeStorage` 加密后独立保存在应用用户目录，不进入 `state.json`、桌宠快照、日志、测试报告或便携包。保存后清空输入，只显示是否已配置；加密不可用时明确提示仅本次使用，不能默默存成明文。
- 接口地址禁止夹带账号/密码，远端默认 HTTPS；本地兼容服务可明确使用回环 HTTP。重定向不能将密钥带到其他地址。聊天正文不按 HTML 执行。
- AI 配置和会话在 `userData/ai/` 单独保存，内部 UUID 命名、原子替换与备份；桥不接受文件路径。生成草稿定期保存；重启显示「上次回复中断」，不自动再次付费请求。历史使用归档，不自动删除输出或旧数据。
- 批量加入任务统一校验标题、数量、时长，带计划 ID 防止重复导入。继续使用原 JSON 版本与未知字段保留机制，不迁移已有个人任务。

## 双人共学规则

- 最多两人，创建返回随机房间码；加入成功后各自获得独立重连标识。房间只同步昵称、可选学习目标、共学状态、共同计时、房间文字与互动事件。个人任务列表、AI 私聊、API Key、桌面画面和鼠标轨迹不上传给对方。
- 双方准备后，主持人选择时长并开始；主持人暂停/继续/结束。参与者可取消准备、发消息、打招呼或离开。共学专注与个人专注互斥；已有个人计时必须让用户明确处理，不能偷偷覆盖。
- 服务端决定唯一轮次 ID、截止时间和累计有效时间，客户端按校准后的服务时间显示。不能让两个客户端各自到期就发奖。
- 掉线时暂停本轮，保留席位约 90 秒；重连恢复完整状态，双方准备后由主持人继续。主持人明确离开或席位超时，提前结束本轮，剩余成员成为主持人。服务重启后未完成轮次暂停，不把停机时间当作专注。
- 完整共学每人奖励 5，个人任务完成奖励仍独立为 10。内部结算把唯一轮次记录与统计奖励在一次本地保存中提交；重复回执、重连和保存重试不重复加奖。共学不会替双方自动完成个人任务。
- 支持真实等待、满员、服务不可达、无效房间码、连接中、断线、重连、对方离开等状态；消息和互动按 ID 去重并限频。

## 跨网络服务与交付边界

跨网络必须有双方都能访问的共学服务端，房间码本身不能完成网络穿透。一起开发可独立运行、自行部署的 Node 共学服务端，支持 WSS 公网连接与本机隔离验收；客户端设置提供服务地址。正式公网地址、域名、TLS、主机和部署方式待提供相应环境时确定，公开部署按用户规则另获授权；本轮不修改 Windows 防火墙、系统配置或安装全局依赖。

没有公网服务地址时仍可完整实现客户端和服务端，并用真实两实例验收协议与互动；不能声称已完成不同网络的真实连通验证。AI 实测同样需使用者在软件里自行配置连接并主动测试，不在对话中索要或记录密钥。

## 结构约定与实施顺序

整体确认后先更新根 `AGENTS.md`、PRODUCT、接口及新页面设计合同，将首版无联网范围改为默认本地、用户主动配置的联网扩展。

- `src/main/ai-*.cjs`：AI 协议、请求生命周期与独立存储；`src/main/study-client.cjs`：房间连接、身份与重连。
- `src/shared/`：新增 AI/共学输入校验与协议定义；原核心状态仅扩展批量任务与内部共学奖励去重，保留既有语义。
- `src/renderer/`：新增页面控制、聊天、任务拆解预览、共学与配置界面；复用已有主题、字体、动画适配和控件。
- `server/`：独立共学服务端、项目本地依赖、启动说明与测试；创建前补根目录职责和 `server/AGENTS.md`，明确源代码、服务数据及隔离测试数据位置。服务器不默认包含个人软件存档。
- `tests/`、`scripts/`：协议/状态测试与真实 Electron 双实例验收；所有验收数据、截图和连续帧仍放 `artifacts/`。新增依赖仅安装在对应项目内，保留旧包和失败报告。

实施分三步但同属一轮交付：① AI 配置/聊天/流式与保存；② 拆解预览/任务批量加入与动画反馈；③ 服务端/共学客户端/两实例验收。交付独立 0.2.0 Windows 便携包、共学服务源码及启动说明、实际验证报告，核对原有任务与设置后再替换当前运行版。

## 验收标准

1. 本地 HTTP/SSE fixture 覆盖三协议、分块/结束、取消、超时、鉴权失败、限流、损坏响应与密钥不进入快照/日志；本地测试不能冒充真实厂商连接。
2. 隔离 Electron 实测配置、流式显示、会话切换/停止/重启恢复、拆解编辑/批量入库/重复拒绝，原任务与个人计时继续可用。
3. 一个真实共学服务＋两个独立 userData 的真实 Electron 实例：建房/加入/第三人拒绝、双方文字互通、准备门禁、主持人权限、计时一致、断线/重连、离开、服务重启和结算去重；个人数据互不串。
4. 保留现有桌宠行为，捕获真实连续帧验证双方小球和打招呼动画；截图验证浅/深、默认/最小窗口与大字号。
5. 全部必要 test/check/smoke 和便携包审计通过，独立界面复核后升级；真实 AI 厂商和不同网络的可达性仅在对应实际请求与环境验证后记为通过。
